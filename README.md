# Christian Lemer

Brussels — Fellow, Medical Data at Boston Scientific.

Fortran came first — when the mainframes were slow.  
C and C++ where the systems would go.  
Perl had its moment — it didn't last long.  
Guido's Python was already strong.

Eiffel and Haskell — academic and fine.  
Oberon too — Wirth's hand on every line.  
European CS in the nineties had spine —  
contracts, types, lambdas, by careful design.

A standard co-authored, an industry call.  
The tools never stopped — they won't stop at all.

Python kept pace as the notebooks grew —  
Jupyter first, then Marimo too.

Daily gear, all Rust to the core:  
fd, rg, ghostty, starship — and more.

Centaur — Kasparov's word, decades grown.  
Claude as horse-half. What neither makes alone.

Tekhnē over automaton.
